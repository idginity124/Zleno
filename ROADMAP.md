# Zleno yol haritası / Roadmap

Bu sayfa geliştirme yönünü gösterir. Tarihler ve platform yayınları; test sonuçlarına, mevcut zamana ve bütçeye bağlıdır.

| Alan / Area | Mevcut durum / Current status | Sonraki hedef / Next goal |
| --- | --- | --- |
| Windows | Microsoft Store’da yayında / Available | Kullanıcı geri bildirimleri ve kararlılık / Feedback and reliability |
| Android | Google Play test süreci / Testing | Cihaz testleri ve sorunların giderilmesi / Device testing and fixes |
| Linux | Paketleme hazırlığı mevcut / Packaging groundwork | Derleme, kurulum, ses ve masaüstü davranışlarını doğrulama / Build and runtime validation |
| macOS | Hedeflenen platform / Target | Mac üzerinde derleme ve test, dağıtım gereksinimlerinin değerlendirilmesi / Build, test, distribution assessment |
| Dil / Language | Türkçe / Turkish | İngilizce arayüz / English interface |
| Altyapı / Infrastructure | Sınırlı kişisel bütçe / Limited personal budget | Kaynaklar elverdikçe kapasite ve sürekliliği geliştirme / Capacity and reliability as resources allow |

Önerilerini Issues üzerinden paylaşabilirsin. Bu depo uygulama kaynak kodlarını içermez.

Suggestions are welcome through Issues. Application source code is not included in this repository.
