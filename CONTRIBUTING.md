# Geri bildirimle katkıda bulun / Contribute feedback

Bu depo Zleno’nun tanıtımı, indirme bağlantıları ve kullanıcı geri bildirimleri içindir. Uygulama kaynak kodları yayımlanmadığı için uygulama koduna yönelik pull request kabul edilmez.

Türkçe veya İngilizce hata bildirimi, özellik önerisi ve belge düzeltmesi paylaşabilirsin. Issues bölümünde uygun formu seç; hata bildirirken platform, cihaz, sürüm ve tekrarlama adımlarını belirt. Görsellerden ve kayıtlardan kişisel bilgileri çıkar.

English: This repository hosts product information and feedback, not application source code. Bug reports, feature suggestions, and documentation corrections are welcome in Turkish or English. Please include platform/version details and reproduction steps, without personal data or credentials.
