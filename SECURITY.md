# Güvenlik / Security

Güvenlik açıklarını, hesap verilerini veya erişim anahtarlarını herkese açık issue olarak paylaşma. GitHub profilindeki iletişim seçeneklerini veya [geliştiricinin sitesini](https://www.ekrembulgan.com) kullanarak önce özel iletişim kur. Özel güvenlik bildirimi etkinse Security → Advisories → Report a vulnerability seçeneğini kullanabilirsin.

Please report security concerns privately through the maintainer’s profile contact options or [website](https://www.ekrembulgan.com). If private vulnerability reporting is enabled, you can use GitHub’s Security tab. Do not post credentials, personal data, or exploit details in public issues. No guaranteed response time is offered.
