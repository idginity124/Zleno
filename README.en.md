<details>
<summary>Linux compatibility and installation</summary>

The 0.1.9 test release includes an Arch / CachyOS package and experimental DEB/RPM packages. Built on CachyOS x86_64 with glibc 2.44; compatibility and real-device testing on other distributions are incomplete. AppImage preparation is ongoing. GPG signatures are provided.

[Linux guide](docs/LINUX.md) · [Changelog](CHANGELOG.md)

</details>

<h2 align="center">Join the Android test</h2>
<p align="center">1. Join the <a href="https://groups.google.com/g/zleno">Zleno Google Group</a>.<br>2. Accept the <a href="https://play.google.com/apps/testing/com.zleno.app">testing invitation</a>.<br>3. Install Zleno from <a href="https://play.google.com/store/apps/details?id=com.zleno.app">Google Play</a>.</p>
<p align="center"><sub>Use the same Google account for all three steps. If access is unavailable, check group membership and testing enrollment, then try again later.</sub></p>
